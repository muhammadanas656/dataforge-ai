## 🚀 How to Use Key Features

### 1. Tabular Data Cleaning (`/clean`)
1. **Upload Dataset:** Drag & drop any CSV, JSON, or Parquet file.
2. **Review Data Dictionary:** Inspect auto-detected semantic types and missing value percentages.
3. **1-Click Auto-Pilot:** Click **Run Auto-Pilot** to automatically impute nulls via MICE, clip IQR outliers, and standardize text formatting.
4. **Reversible Diffs:** Inspect cell-by-cell changes before committing to export.

### 2. Web Intelligence & Lead Extraction (`/intel`)
1. **Target Search:** Enter any company, technology, or research URL.
2. **SSRF Pre-Flight Check:** The system verifies the URL against cloud metadata blocking rules.
3. **Live Search Telemetry:** Observe live stage progress and bandwidth consumed in real-time.
4. **Data Quality & Privacy Check:** Content passes through character bounds, relevance scoring ($\ge 0.15$), and PII scrubbing.
5. **Instant Ingestion:** Extracted knowledge is indexed into RAG and distilled into local zero-token memory.

### 3. Strategic Invention & Risk Simulation (`/niche`)
1. **Define Contradiction:** Enter engineering or business trade-offs (e.g. *"High Throughput vs Low Memory"*).
2. **TRIZ Resolution:** Resolves trade-offs using Altshuller's 40 Inventive Principles.
3. **Fat-Tail Modeling:** Simulates black-swan shocks via heavy-tailed Student-t ($df=3$) and Pareto distributions.
4. **Value at Risk:** View VaR 95% and Expected Shortfall metrics.

### 4. Causal DAG Discovery (`/eda`)
1. **Select Target Feature:** Choose your target column (e.g. `churn_rate`, `revenue`).
2. **Precision Matrix Inversion:** Calculates partial correlations controlling for confounders.
3. **Directed Graph:** Explores root-cause causal arrows proving true drivers versus accidental correlations.

### 5. Generative Design & SVG Studio (`/export` or via Copilot)
1. **Prompt Design:** Ask Copilot *"Generate a 2027 dark neon icon for cloud security"* or *"Extract the visual DNA from [Website]"*.
2. **6D Fitness Evaluation:** Validates WCAG AAA contrast ($\ge 7.0:1$), HSL color harmony, and scalability.
3. **Multi-Size Preview:** Inspect live rendering across 16px, 24px, 32px, 48px, 64px, and 96px.
4. **1-Click Code Download:** Download ready-to-use **React JSX**, **Vue 3 SFCs**, **SVGs**, or **Figma Design Tokens JSON**.

## 🤖 Interacting with AI Copilot

### Simple Mode (ELI5 Toggle)
Toggle the **"Simple Mode (ELI5)"** switch in the Copilot header to switch between beginner-friendly everyday analogies and technical mathematical breakdowns.

### Scenario-Specific Impact Queries
Ask questions formatted like:
- *"How will Causal DAGs be helpful for an e-commerce checkout churn scenario?"*
- *"How does TRIZ help if I'm scaling a high-frequency trading bot?"*
- *"How will SSRF security protect a healthcare patient portal data pipeline?"*

Copilot provides:
1. **Direct Business ROI:** Clear, practical value for your exact industry.
2. **Real-World Walkthrough:** Concrete before vs after scenario comparison.
3. **Critical Mistake Avoided:** Exact costly mistake prevented.
4. **Direct Action Card:** Click `[👉 Open Studio]` to navigate directly to the feature.
